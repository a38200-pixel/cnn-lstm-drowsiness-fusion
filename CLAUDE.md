# Repository Working Instructions

Before any project work:

1. Read [docs/PROJECT_WORKFLOW.md](docs/PROJECT_WORKFLOW.md).
2. Read [docs/EXECUTION_PLAN.md](docs/EXECUTION_PLAN.md).
3. Read the latest relevant entries in [docs/PROGRESS.md](docs/PROGRESS.md).
4. Identify the current execution-plan step before changing code or documents.
5. Perform only the current planned step.
6. Validate the work.
7. Update `docs/PROGRESS.md` after every meaningful completed step.
8. If the plan changes, update `docs/EXECUTION_PLAN.md` before continuing with the changed approach.
9. Run `git diff --check` and identify the next step before completing the task.

Do not invent experiment results, mark unexecuted work as completed, or silently change the experimental plan. Record failed, interrupted, and resumed work. Keep implementation and documentation consistent.

For detailed repository rules, follow [docs/PROJECT_WORKFLOW.md](docs/PROJECT_WORKFLOW.md).
